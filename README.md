## 👋 About me

I'm a web developer who leans hard into the front end. I build with **React, Next.js and TypeScript**, and back them with **Node.js, Express and MongoDB** (or PostgreSQL when the data calls for it).

- 🎨 I care about the details users feel: smooth motion, accessible components, and layouts that work just as well **right-to-left in Arabic** as in English.
- 🤖 Lately I've been building **AI features that stay trustworthy**: answers grounded in real data, never guesses.
- 🛍️ I also build e-commerce storefronts and themes (Shopify, Salla).
- 🌱 Always learning; right now that's deeper backend, testing and system design.
